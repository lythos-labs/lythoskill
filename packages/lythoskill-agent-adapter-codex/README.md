# @lythos/agent-adapter-codex

Codex CLI adapter for [`@lythos/agent-adapter`](https://github.com/lythos-labs/lythoskill/tree/main/packages/lythoskill-agent-adapter/). Spawns `@openai/codex` agent processes for arena cross-player mode.

## Usage

This package has no standalone CLI. It is consumed through the `@lythos/agent-adapter` registry.
