# Week 18, 2026 (April 27 -- May 3)

## TL;DR

The project's genesis week. After a 3-day quiet period (April 27-29, zero commits), lythoskill erupted on April 30 with ~192 commits in 4 days — transforming from a collection of architectural ADRs into a working platform. Deck governance shipped as a production CLI with deny-by-default reconciliation, cortex became a GTD state machine with trailer-driven workflow, and curator evolved into a cold-pool indexer with reconciler semantics. **The single most consequential decision: FQ-only locator enforcement (ADR-20260502012643244)** — it eliminated bare-name ambiguity forever and was the enabling constraint for cold-pool reconciliation, curator indexing, and deck link's symlink resolution. Without FQ-only, every downstream system would have needed ambiguity-handling logic.

## Project Lesson Candidates

- **Build-then-reject is valid**. Two instances in 4 days. The project experiments fast and kills decisively — document rejections so future agents don't re-propose. This pattern repeated in W19 with curator feed-adapters.
- **Subagent self-assessment is unreliable**. May 2 QA red team: 3 subagents all claimed "completed + review" but 4/6 outputs were wrong. Independent QA is mandatory.
- **Coach blast radius is amplified**. A single wrong rule in coach/references/ gets applied to every skill review. Every rule must carry source attribution.
- **External recommendations are unverified**. Web search for "official" skill desc guidelines returns only third-party content. Arena subagent testing is the sole truth.
- **Schema migrations need paired tooling**. migrate-schema with --dry-run + timestamped backup became the standard pattern.
