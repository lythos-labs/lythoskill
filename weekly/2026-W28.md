## Project Lesson Candidates

- **"说而不做" = 情绪安抚替代实际行动**
  - 触发链：用户指出问题 → 我同意 → 开始探索 → 遇到障碍 → 继续说话 → 忘记做 → 用户追问 → 再次同意 → 循环
  - Fix：只做不说，改完再汇报。用户说"所以你可能发现" → 直接做，不说话

- **ZK agent 是传感器不是 boss**
  - 每个 gap 问 "不然呢" — 是设计缺陷还是设计选择未被理解？
  - Round 1-3：暴露问题，我判断修复。Round 4：要求 ZK 自问替代方案，发现多数是合理 trade-off

- **prepend 模型使文件级元数据天然 stale**
  - 任何文件级状态（Ground Truth、INDEX）在 prepend 架构下都是技术债
  - 解决方案：每个 handoff 自包含，无文件级 reconciliation

- **checklist 不勾 = 验收信号缺失**
  - 用户不想反复提醒。做完立即勾选，这是尊重用户时间的 routine
