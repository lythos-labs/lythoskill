## Project Lesson Candidates (promote to wiki on second occurrence)

1. **Build-then-reject is a valid project pattern.** Three instances in 10 days: allowed-tools (May 2), leetcode harness (May 4), curator feed-adapters (May 5-8). The project experiments fast and kills decisively. Document the rejection in ADRs so future agents don't re-propose the same discarded idea.

2. **Empty working set = agent without immune system.** The May 7 CPTSD incident proved that when `.claude/skills/` is empty, agents bypass the skill system entirely and start modifying source code directly. Deck link is the project's immune system -- without it, every agent reinvents architecture from scratch.

3. **Subagent self-assessment is unreliable.** May 2 QA red team: 3 zero-context subagents all claimed "completed + review" for their allowed-tools output, but 4/6 skills were actively wrong (empty allowed-tools blocking legitimate commands). Independent QA review is mandatory for agent-produced output.

4. **E2E findings must be allowed to rescope mid-week.** The cold-pool extraction (the week's defining work) was triggered by a production incident, not a sprint plan. Rigid week plans would have suppressed the signal that revealed the architectural defect.

5. **External feedback is a leading indicator.** OpenClaw's first arena test (May 8) revealed onboarding cliffs (per-player auth, runtime gotchas) that internal testing missed. Ship early to get this signal before it compounds.

6. **workspace:\* protocol must never appear in published packages.** v0.9.24 shipped `"workspace:*"` literally to npm. Consumers couldn't resolve it. AGENTS.md now documents this explicitly.
