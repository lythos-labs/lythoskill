# Week 20, 2026 (May 11 -- May 17)

## TL;DR

W20's center of gravity was **the release pipeline growing up through fire**. Six versions shipped in one week (v0.9.50 through v0.14.1), and two of them (v0.11.0, v0.11.1) broke on npm because `workspace:*` literals shipped to the registry. The fix -- `publish.sh` rewrites at publish time, `git checkout` restores -- resolved a pendulum swing between "local correct" and "publish correct" that had silently broken multiple releases. Pre-commit guards were hardened in parallel: cross-package import rejection, private-leak detection, and the dead test counter (`|| true`) that had silently suppressed failures for 4 days were all fixed. By week's end the pipeline had transformed from ad-hoc to hardened.

Meanwhile, **arena architecture crystallized**: judge decoupling (pr-1/2/3, `parseAgentMd` retired), agent-orchestrated as default with `prepare-workdir` + `archive` CLI, the Control Transfer Protocol formalizing stdout/stderr as agent interrupt vectors, and the Seed Bootstrap pattern -- a deck with only the governance skill lets an agent self-expand. The single most important decision: **the publish-time rewrite** (commit `9c1bf4a` on May 13), which made `workspace:*` safe for both local development and npm consumers simultaneously.

## Project Lesson Candidates

1. **Publish-time rewrite is the only correct resolution for `workspace:*` dual-audience tension.** Source stays `workspace:*` for local dev (pre-commit rejects `^x.y.z` on internal deps). `publish.sh` rewrites to `^version` before `npm publish`, then `git checkout` restores. The pendulum had swung between hand-coded versions and `workspace:*` literal across multiple agents because no one synthesized the two-audience constraint into a single pattern.

2. **Seed bootstrap: governance skill alone enables agent self-expansion.** A deck containing only `lythoskill-deck` is sufficient for a zero-knowledge subagent to read the schema, query the catalog, select skills, and compose a working deck. Verified with 2 different task domains (docx + radar chart, landing page + brand compliance). Recursive bootstrap eliminates the cold-start problem for deck composition.

3. **Control Transfer Protocol: CLI stdout/stderr are agent interrupt vectors.** `--dry-run` (prompt injection forward), HATEOAS error templates (exception vector), and path guards (pre-check vector) form a three-channel protocol. The CLI is userspace, the agent is kernel -- exit paths are page fault handlers. This formalization made `prepare-workdir` + `archive` implementable in one session.

4. **Competitive landscape differentiation: side-effect skill observability is a structural moat.** Two emerging competitors (`agent-skills-eval`, `skills-vote`) both use `openai.invoke()` prompt-completion evaluation -- they can only observe text output. Arena evaluates artifacts (HTML, PDF, docx, images) that side-effect skills produce. This is not a feature gap; it's a different evaluation class that prompt-completion frameworks cannot reach regardless of prompt iteration.
