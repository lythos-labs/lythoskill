### Critical Insight: Theory ≠ Practice

The probe UX audit task passed ZK Review at 9/10 (theoretical understanding), but **trial usage dropped to 5/10**. This reveals a fundamental ZK Review limitation:

> **Reading docs ≠ using tools. Output-layer UX issues are invisible to document review.**

### ZK Review Methodology Upgrade

**Old model**: Read → Review → Fix → Converge → Execute
**New model**: Read → Review → Fix → Converge → **Trial** → Discover output gaps → **New task** → Review → Execute

**Required personas**:
1. **Zero-knowledge reader**: Finds documentation/scope gaps
2. **Trial user**: Finds output/interaction gaps (invisible to readers)
3. **Repeat reviewer**: Verifies fixes after trial feedback
