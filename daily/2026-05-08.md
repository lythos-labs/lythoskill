## 3. working_set 解析修正 (ADR-20260508074057834)

**问题**: `--deck ./decks/my.toml` 时 working_set 解析到 `./decks/.claude/skills/`而非 cwd。

**方案 C**: `--deck` 显式时 PROJECT_DIR = cwd。同时 link 日志输出绝对路径：

```
📋 deck:      /absolute/path/to/skill-deck.toml
📁 working_set: /absolute/path/to/.claude/skills
🗄️  cold_pool:   /Users/.../.agents/skill-repos
```

agent 看到路径就知道技能装哪了——内文档化。

## 4. URL Deck Fetch (ADR-20260508075301691)

**发现**: quick-agent.sh 已支持 URL deck，但 CLI 用户还需两步（curl + link）。

**实现**: `deck link --deck https://.../deck.toml` → `fetch()` + 保存 + link。一行完成。

**技术**: `spawnSync('curl')` → 原生 `fetch()`（AbortSignal.timeout，HTTP_PROXY 自动生效）。
