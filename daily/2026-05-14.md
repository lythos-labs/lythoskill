### Key design decisions

1. **parseAgentMd retired** — arena runners (single + vs) no longer use it. Remains for legacy test fixtures only.
2. **Judge input = natural language** — `JudgeInput.criteria: z.string()`, read from judge.md or arena.toml inline. No object rendering.
3. **Judge output = strongly typed** — `JudgeVerdict.parse()` enforces JSON contract.
4. **Toolbox composition** — `runLLMJudge`, `readCheckpoints`, `computePareto` are free functions, importable anywhere.
5. **Zod TS pseudo-code in judge prompt validated** — reduces hallucination, retained.
