### Pitfalls

- **VitePress YAML parsing**: Unicode `→` in frontmatter details breaks parser. Use `>` or `&gt;` inside YAML blocks. In markdown body, `→` is safe.
- **ESM/CJS config**: `import { defineConfig } from 'vitepress'` fails with local vitepress install. Use plain object `export default`.
- **VitePress dev picks up root .md files**: `INDEX.md`, `README.md` at project root get parsed as Vue SFCs. Fix: `srcExclude: ['../**']`.
- **CWD matters for git commands**: After `cd site`, `git add site/` fails. Always use absolute paths or `git -C`.
- **npm install in site/ creates package-lock.json**: Must be gitignored. Added `site/node_modules/`, `site/package-lock.json`, `site/.vitepress/cache/` to root `.gitignore`.
- **Site narrative took 4+ iterations**: Initial approach was wrong (started from our concepts). User feedback drove structural restructure. The lesson: strangers don't share our context — they need the problem before the solution.
